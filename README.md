# Faiz & Muna's Journal

A private two-person journal for weight, BMI, exercise and daily notes. It installs on a phone like an app and works offline.

**Live site:** [faiz-muna-journal-c43ab.web.app](https://faiz-muna-journal-c43ab.web.app/)

Built with plain HTML, CSS and JavaScript (no framework, no build step), hosted on Firebase with data in Firestore.

## Run it locally

```bash
npm ci
npm run dev
```

The app opens at http://localhost:5000 and the emulator UI at http://localhost:4000. See [CLAUDE.md](CLAUDE.md) for how it works.
